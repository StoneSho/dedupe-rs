# dedupe-rs

用 Rust 写的**本地重复文件清理 CLI**：扫描目录，找出内容完全相同的文件，默认只报告、不删除。

适合当作「边学 Rust、边做能自己用的工具、还能写进作品集」的第一作。

仓库：https://github.com/StoneSho/dedupe-rs

---

## 这个项目是干什么的？

硬盘里经常堆着同一张图、同一份下载、同一段录屏的多个副本——名字不同、路径不同，肉眼很难清。

`dedupe-rs` 做的事很直接：

1. **递归扫描**你指定的目录（不跟随符号链接）
2. **先按文件大小分组**——大小不同，内容不可能相同，直接跳过哈希
3. 对同大小的文件算 **SHA-256**，内容哈希相同才算真正重复
4. 每一组里**保留一份**，其余标成「候选」
5. **默认 dry-run**：只打印报告；真要删，必须显式加 `--delete`，并再确认一次（除非加 `--yes`）

它解决的是「内容级重复」，不是「文件名像不像」的模糊相似去重。

### 为什么要做这个？

- **自己用得上**：清理下载目录、备份盘、相册导出时真的省空间
- **学 Rust 顺**：CLI 参数、文件 I/O、`HashMap`、所有权、`Result`/`?`、模块拆分都能练到
- **作品集好讲**：两阶段去重、安全默认、可复现的命令行工具，比「练习题仓库」更有说服力

## 核心思路（算法）

```text
目录
  → 遍历普通文件（跳过空文件 / 符号链接）
  → 按 size 分桶
  → 仅对「桶内 ≥ 2 个」的文件算 SHA-256
  → 按 digest 再分桶
  → 每桶保留 1 个，其余为候选
```

**保留规则（v0.1）**

1. 路径字符串更短的优先保留
2. 一样长则修改时间更早的优先
3. 再相同则按路径字典序

> 规则可以以后改成「最新的留下」或「指定目录优先」；v0.1 先固定、可解释。

- 递归扫描指定目录

## 构建与运行

```bash
git clone https://github.com/StoneSho/dedupe-rs.git
cd dedupe-rs

# 检查能否编译
cargo check

# 跑测试
cargo test

# Debug 运行（只报告）
cargo run -- /path/to/your/folder

# Release 构建
cargo build --release
./target/release/dedupe-rs /path/to/your/folder
```

## 用法

```text
dedupe-rs <PATH> [--delete] [--yes]
```

| 参数 | 含义 |
|------|------|
| `PATH` | 要扫描的目录 |
| `--delete` | 删除各组的候选文件（仍会确认，除非加 `--yes`） |
| `--yes` | 与 `--delete` 一起用时，跳过交互确认 |

### 示例

```bash
# 1) 只看报告（推荐永远先这样）
cargo run -- ~/Downloads

# 2) 确认无误后再删，会提示输入 yes
cargo run -- ~/Downloads --delete

# 3) 脚本场景：跳过确认（请确认你知道自己在删什么）
cargo run --release -- ~/Downloads --delete --yes
```

### 输出长什么样

```text
已扫描 1284 个文件（跳过空文件 3 个）

发现 2 组重复文件：

── 组 1 (sha256: a1b2c3d4e5f6)
  保留: /Users/you/Downloads/photo.jpg
  候选: /Users/you/Downloads/photo (1).jpg

当前为 dry-run。若确认要删除候选文件，请加上 `--delete`（建议先备份）。
```

## 安全说明（请认真看）

1. **默认不删任何东西**。没加 `--delete` 就只是报告。
2. 删除不可自动撤销。重要数据请先备份或先拷贝到别处再试。
3. 不要对着系统根目录、系统盘关键路径乱跑。
4. 本工具按**字节内容**判重：两个文件哈希相同，内容就相同；它不会帮你判断「哪张照片构图更好」。
5. 空文件会被跳过（大小为 0），不会参与去重。

## 项目结构

```text
dedupe-rs/
├── Cargo.toml
├── LICENSE
├── README.md
└── src/
    ├── main.rs    # CLI 入口（clap）
    ├── scan.rs    # 遍历目录 + 按大小分组
    ├── hash.rs    # SHA-256 + 组成重复组
    └── report.rs  # 打印报告 / 删除候选
```

学习时建议阅读顺序：`main.rs` → `scan.rs` → `hash.rs` → `report.rs`。
